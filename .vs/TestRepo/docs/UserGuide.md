# User Guide

## Dashboard

The dashboard provides quick access to:

- Projects
- Reports
- Notifications
- User Profile

---

## Creating a Project

To create a project:

1. Click **New Project**.
2. Enter the project name.
3. Add a description.
4. Select a department.
5. Click **Save**.

---

## Editing a Project

1. Open the project.
2. Click **Edit**.
3. Update the required fields.
4. Click **Save Changes**.

---

## Searching Projects

Use the search box to search by:

- Project Name
- Department
- Owner

---

## Exporting Reports

Navigate to **Reports**.

Supported export formats:

- PDF
- Excel
- CSV

Click **Export** to download the report.

---

## Notifications

Notifications appear in the upper-right corner.

Unread notifications are highlighted until viewed.
