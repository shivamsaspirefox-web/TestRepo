# Installation Guide

## Overview

This document explains how to install the Sample Desktop Application.

---

## System Requirements

Before installing, make sure your computer meets the following requirements:

- Windows 10 or Windows 11
- .NET 8 Runtime
- Minimum 8 GB RAM
- 500 MB free disk space
- Internet connection for activation

---

## Installation Steps

1. Download the installer from the company portal.
2. Double-click the installer.
3. Accept the license agreement.
4. Select the installation folder.
5. Click **Install**.
6. Wait for the installation to complete.
7. Launch the application.

---

## First Login

After installation, enter:

- Email Address
- Password

Click **Sign In**.

---

## Updating the Application

Navigate to:

**Settings → Check for Updates**

If a new version is available, click **Install Update**.

---

## Uninstall

To uninstall the application:

1. Open Control Panel.
2. Select **Programs and Features**.
3. Choose **Sample Desktop Application**.
4. Click **Uninstall**.
